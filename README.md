# VYBET

Projeto organizado em duas partes:

- `frontend/` — interface atual do VYBET (Futebol + Cassino).
- `backend/` — API Node.js/Vercel + Supabase da Fase 1.

## Próximos passos
1. Criar/configurar o projeto no Supabase.
2. Executar `backend/supabase/schema.sql` no SQL Editor.
3. Copiar `backend/.env.example` para `backend/.env.local` e preencher as variáveis localmente.
4. Não enviar `.env.local` ao GitHub.
5. Implantar/testar o backend.
6. Conectar o frontend aos endpoints da API.

O frontend foi mantido separado do backend para evitar misturar arquivos públicos com configurações privadas da API.
